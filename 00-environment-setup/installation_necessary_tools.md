# VAPT Lab - Installation & Environment Setup

## 1. Host Machine
- OS: Windows 11 Pro
- CPU: Intel Core i7-1165G7
- RAM: 16 GB
- Virtualization: Intel VT-x Enabled [# Intel VT or Virtual Technology is a hardware feature built in the processor. It lets the physical computer to run multiple independent virtual machines at the same time]
- Intel VT-d: Enabled [# Intel VT-d or Virtual Technology Directed I/O lets the virtual machines to safely and directly access the hardware devices like Graphics card, Network Adapter, etc.]
